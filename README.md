# MedWise

MedWise is a health management application available on mobile and the web.
This repository contains the documentation and user guide for both experiences.

## Documentation

- [MedWise user guide](docs/guide.md) — getting started, using the mobile app
  and web app, account safety, and troubleshooting.

## At a glance

| Experience | Best for |
| --- | --- |
| Mobile app | Managing health information while away from a computer |
| Web app | Reviewing information and completing longer tasks on a larger screen |

The mobile and web apps use the same account. Changes made in one experience
should be available in the other after synchronization.
